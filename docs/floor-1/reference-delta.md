# Floor 1 Reference Delta

## Intentionally retained from the reference image

- Warm, dense isometric office-management-game composition
- Crisp pixel edges, nearest-neighbor scaling, hard-edged highlights, and limited cohesive palettes
- Partial-height cutaway walls and an immediately readable room hierarchy
- A darker cyan Central Nexus as the dominant visual focal point
- Department-specific color families, furniture groupings, monitors, plants, shelves, and populated meeting spaces
- North-side Executive/Security/Operations organization; western Engineering; southern Reception/Project; eastern Knowledge/Quality
- A busy but navigable workplace with visible circulation around the Nexus and controlled areas

## Intentional written-specification corrections

- Project Coordination is an open area separate from the one-person manager office; both vacant Project desks are in the open area.
- The Sandbox uses one enclosed transfer corridor, a controlled containment vestibule, and four cells that open only into that vestibule.
- Independent Audit has its own controlled entrance and evidence storage rather than an unrestricted opening into Security and Approval.
- The checkpoint spans the entrance flow and has no modeled bypass; post-checkpoint temporary, production, and secure-evaluation routes are distinct.
- The Agent and Release Review room has direct Project access plus a separate restricted Quality-side entrance.
- Operations contains exactly three four-console pods with the specified permanent vacancies and shared surge positions.
- Duplicate southern conference rooms were removed; the floor has exactly the five specified conference rooms.
- Future wing connections are sealed construction boundaries, not circulation paths through Executive offices.

These are deliberate corrections, not failures to copy the image.

## Simplified for the primitive-based prototype

- Original low-resolution textures use reusable silhouettes and palette tints rather than individually illustrated production sprites.
- Fine text shown on review, incident, lineage, quality, and briefing displays is represented by recognizable screen layouts and nearby concise labels.
- Furniture orientations share a compact set of reusable isometric forms.
- Walls use consistent generated faces rather than hand-painted per-room tile seams and weathering.
- Lighting is expressed through palette, hard highlights, and shadows rather than dynamic light maps.

## Later sprite-art pass

- Add bespoke character hair, clothing, seated poses, and department accessories while keeping the current scale.
- Replace reusable display silhouettes with unique pixel screens for incident timelines, architecture diagrams, lineage, approvals, and Daily Briefing metrics.
- Add per-room wall trim, richer wood/tile patterns, small personal items, and additional plant variants.
- Refine door animations, glass reflections, elevator indicators, construction scaffolding, and Nexus hologram frames.
- Add optional subtle idle animation without introducing movement or runtime simulation.
