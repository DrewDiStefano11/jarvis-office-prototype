# Approved Floor 1 visual conversion plan

Status: representative proof gate only. Full-floor replication is not authorized until the user approves the proof screenshots.

## Authoritative sources

1. Written Floor 1 counts, security, and reachability rules.
2. `image-1.png`: broad symmetrical architecture and room composition.
3. `image-3.png` and `image-4.png`: populated density, furniture richness, lighting, and atmosphere.
4. `image-2.png`: 30-agent identity and clothing variety.
5. Existing typed Floor 1 domain IDs and interaction/camera architecture.

No supplied image is used as a runtime background or copied into production assets. The conversion uses original modular, data-backed pixel assets.

## Target architecture

- World: 1920 × 1280 logical units, projected through the existing 2:1 isometric transform.
- Footprint: broad stepped octagonal massing using 84–94% of the card-safe viewport width at Fit Floor.
- Central axis: Executive → Nexus → controlled lobby → checkpoint → public entrance.
- Left wing: Security, Agent Platform, Plugins, Knowledge, west expansion.
- Right wing: Reliability/Operations, Engineering, Project, Quality, Sandbox, east expansion.
- Distributed support: five conference rooms and four focus rooms placed next to their owning departments.
- Internal transitions: one main elevator interface and two internal stairs, all reached from controlled circulation.
- Containment: restricted route → transfer corridor → shared vestibule → four independent cells.

## Proof-gate scope (approximately 25%)

The first rendered proof includes:

- Central Nexus segment with four shared consoles.
- Software and Platform Engineering cluster.
- Jarvis Command private office.
- Agent and Release Review conference room.
- Engineering/Agent Platform focus room.
- Public entrance, vestibule, reception, waiting, intake, checkpoint, and controlled-lobby segment.
- Sandbox transfer route, vestibule, and New Agent cell.
- Eight or more unique occupants, standing and seated.
- Four chair families, four desk/table families, lighting, particles, movement overlay, and door-access overlay.

The unimplemented rooms remain represented only in the conversion plan; the normal Floor 1 renderer remains available as a rollback point.

## Proof acceptance gate

The proof cannot advance to full conversion if characters remain blocky, furniture reads as recolored rectangles, rooms feel sparse, doors are unreachable, circulation is cramped, colors are neon-heavy, or the fit view wastes the widescreen viewport. Evidence must include overview, medium, close, characters, seated integration, furniture, movement, doors, and effects states, plus a side-by-side reference comparison and written critique.
