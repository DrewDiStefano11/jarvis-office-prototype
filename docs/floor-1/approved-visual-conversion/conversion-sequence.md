# Controlled conversion sequence

1. Preserve and commit the approved plan and current rollback state.
2. Build reusable proof data, asset profiles, and proof renderer.
3. Render the representative 20–30% cluster and capture overview/medium/close evidence.
4. Compare source and implementation in the same composite; fix all P0/P1/P2 visual defects.
5. Stop for user approval.
6. If approved: Nexus and central circulation.
7. Entrance, reception, waiting, intake, checkpoint, lobby.
8. Executive and Security clusters.
9. Reliability and Operations.
10. Agent Platform, Engineering, and Plugins.
11. Project, Knowledge, and Quality.
12. Remaining conference/focus/support spaces.
13. Sandbox route, vestibule, and all cells.
14. Complete population, vacancies, poses, and accessories.
15. Lighting, particles, labels, responsive camera, exact-count/security/walkability audits, and final evidence.

Every post-approval cluster receives its own screenshot inspection and rollback commit. No full-floor replication begins from this plan without explicit user approval of the proof gate.
